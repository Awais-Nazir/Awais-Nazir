## Projects

- [Hisab AI Agent](https://github.com/Awais-Nazir/Hisab-AI-Agent) ([live](https://hisab.awaisnazir.tech/chat)): a FastAPI agent for expense tracking. You write in Roman Urdu or English, the model proposes an entry, and nothing is saved until you confirm. A 20-case eval set checks its tool calls.
- [Knowledge Assistant](https://github.com/Awais-Nazir/knowledge-assistant) ([live](https://ai-rag.awaisnazir.tech)): a multi-tenant RAG backend in FastAPI and PostgreSQL. It combines pgvector and BM25 search, reranks the results and streams answers. Still in development.
- [Hisab Kitab](https://github.com/Awais-Nazir/hisab-kitab-ag) ([live](https://hisab.awaisnazir.tech)): a mobile-first expense tracker for cash, bank accounts, SadaPay and NayaPay, with a ledger of who owes whom. Next.js, Prisma and PostgreSQL.
- [Solverse PDF Tools](https://github.com/Awais-Nazir/SOLVERSE-PDF_tools) ([site](https://pdf-tools.awaisnazir.tech)): an offline Windows app that merges and splits PDFs from the right-click menu. Version 2.0.0 is released.

Hisab Kitab, the agent and the Knowledge Assistant app all need an account to try.
